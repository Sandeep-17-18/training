## ◈ About Me

I'm currently a **3rd Year B.Tech Computer Science** student with a strong interest in **Machine Learning, Python development, and web technologies.**

What began as a journey focused on learning and placements has evolved into a deeper purpose — **building meaningful, data-driven, and high-impact solutions through technology.**

My foundation lies in **Python**, **Machine Learning**, **Django Web Framework**, **Data Analysis**, and performance-focused application development.

I have hands-on experience building real-world ML projects including a **Life Expectancy Prediction model** and an **HOG Feature Extraction** image processing system, gaining practical knowledge of end-to-end model development and deployment.

Curiosity and project-based learning transformed my mindset — from just writing scripts to **thinking in data pipelines, model architectures, and intelligent systems.**

> _Every dataset, every model, every iteration is a chance to learn something new. Growth never stops._
